## 一、已修正的錯誤或過時資料
| 日期 | 原本說法 | 修正 |
|---|---|---|
| 2026-10-27 | Agent SDK 獨立額度暫停，`claude -p` 一律計入訂閱額度，Max 沒有其他 API 預算 | 2026-10-07 起 Max 5x 每月附送 US$100 API credit（20x 為 US$200，Pro 沒有），要連結 Console 組織領取；涵蓋 API、Agent SDK、Managed Agents 和用該組織 API key 執行的 `claude -p`。用訂閱登入的 `claude -p` 仍計入訂閱額度 |
| 2026-10-27 | Hermes 經 tmux 操控 Claude Code 屬灰色地帶（以為主要問題在 tmux） | Hermes 本身的 Anthropic OAuth 路線會自動借用 Claude Code 的登入並自稱 Claude Code；Hermes 文件寫明只扣 Max 的 extra usage。Anthropic 表示第三方工具用訂閱不在條款允許範圍。要主動關閉 Hermes 借用登入的功能 |
| 2026-10-16 | MacBook Pro 是公司配發 | 本人私人擁有，同時做公司專案，公司已同意；沒有公司 MDM（2026-10-27 確認） |
| 2026-10-06 | ChatGPT：Max 用戶有獨立的 Agent SDK / `claude -p` 額度（5x 每月 US$100） | 這個計劃 2026-06-15 已暫停；2026-10-07 起改為 Max 附送的每月 API credit（見上） |
| 2026-10-06 | Claude：256GB 只能用低品質量化跑中型模型 | 不完整：256GB 可以放下 GLM-5.3-Flash（4-bit 約 204GB），128GB 放不下；但它的綜合分數低於 Qwen3.8-27B |
| 2026-10-06 | Claude：TRELLIS.2 / Hunyuan3D 可以在 Mac 本地跑 | 要補充：官方版本針對 CUDA，Mac 版本是社群移植，較慢、較不穩定；大量生成以雲端 GPU 為先 |
| 2026-10-05 | 網上傳言：M5 Ultra 等於 RTX 5090 | 只在 Blender 渲染成立；整體約 RTX 4080 級，遊戲約 RTX 5070 級 |
