## 二、背景事實（影響決定）
- 本人是 Sword of the Guardian（2018，Steam + Switch，Unity）的一人開發者；當年用 3D 預渲染 sprite + 3D 背景的 2.5D 做法。
- 舊美術資產可用於續作，**音樂除外**。
- 當年因數值測試和網上連線做不到而放棄的設計（打寶升級、多人連線），這次可以重新評估。
- 可投入時間：每星期約 10 小時（週末約 6 小時、平日約 4 小時）。人手時間是整個計劃的真正瓶頸。
- 舊作評價：推薦數字被善意灌水；有實質內容的評價一致指出動作僵硬、節奏慢、內容重複、缺乏成長系統、存檔、按鍵、畫面和場景等問題。
- **2026-10-07 起 Claude Max 5x 每月附送 US$100 API credit**（2026-10-27 查到，見 08；升級 Max 前重新核實，見待決 #23）（Max 20x 為 US$200），要在 claude.ai 帳單設定連結一個 Console 組織才可領取。涵蓋 Claude API、Agent SDK 和用該組織 API key 執行的 `claude -p`；用訂閱登入的 Claude Code 和 `claude -p` 仍計入訂閱額度。見 04 第五部分。
- 帳戶：Claude 兩個（公司、個人）、ChatGPT 一個（個人）、GitHub 兩個（公司、個人）。
- **Claude Code 有官方的手機遙控功能，用 Pro/Max 訂閱登入：** Channels（2026-03 推出，research preview；Telegram、Discord、iMessage 訊息直接送入 Mac 上運行中的 Claude Code session）和 Remote Control（`claude remote-control`，用 claude.ai 或手機 app 操作本機 session）。Hermes 的手機遙控功能大部分可以由官方功能取代。
- **2026-11-05 Mac Studio 實測（Claude Code 在 `billychan` 唯讀檢查；不含 token、IP、序號）：**
  - 硬件：M5 Max（18 核 CPU、40 核 GPU）、128GB、4TB 內置；macOS 27.2；FileVault On。MDM：沒有（來源 `openclaw-to-hermes` 2026-11-02 的 `profiles status`，這次未重查）。
  - 工具（全部在 `billychan`）：Claude Code 2.1.318（claude.ai 登入，**Pro**）、Codex CLI 0.166.0、AO 0.14.8（`ao status --json`：ready、health ok，2026-11-03 起運行）、gh 2.103.3、git 2.54.0（Apple）、uv 0.13.6、Unity Hub，Editor 已裝 Unity 6（6000.6.7f1）和 2017.4.40f1。
  - 未安裝：gitleaks、git-lfs、tmux、bun、Aider、LM Studio（所以 `scripts/install-hooks.sh` 未執行，commit 前沒有自動秘密掃描）。
  - 環境變數：`ANTHROPIC_API_KEY`、`OPENAI_API_KEY` 都沒有設定。
  - 電源（`pmset -g custom`，AC）：sleep 0、autorestart 1、displaysleep 10。
  - GitHub：`gh` 有兩個帳戶（個人 `kahongchan`、公司帳戶）。2026-11-05 經本人授權，active 由公司帳戶改為 `kahongchan`（`gh auth switch`）；**公司帳戶仍然登入，未登出**（待決 #16）。git 沒有全域 `credential.helper`，但 Apple git 的系統設定用 `osxkeychain`，而鑰匙圈有一個 github.com 的 git 憑證，屬哪個帳戶**未核實**。所以 `studio-kb` 的 push 一律經 `scripts/gh-personal.sh`（2026-11-05 實測正常，身份核對為 `kahongchan`）。
  - `studio-kb` 工作副本：`~/Projects/studio-kb`（HTTPS，repo-local 身份為 `kahongchan` noreply，和 `openclaw-to-hermes` 相同）。
  - VPS：Hermes 的 `studio-admin` profile（「Mac Studio 管家」，有獨立 Discord bot），大腦用 **Codex 登入**；**沒有** SSH、shell、檔案或瀏覽器工具。
