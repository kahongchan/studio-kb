# 05 模型與工具清單

> 截至 2026-10-06。模型每個月都在更新，選用前要核實版本和授權。

## 一、各範疇建議
### 程式和規劃
| 用途 | 主力 | 補充 |
|---|---|---|
| 規劃、架構、審查 | Claude（Max） | ChatGPT 做第二意見 |
| 日常寫碼 | Qwen3.8-27B（本地；Apache 2.0；262K context；支援看圖） | Qwen3-Coder-Next 80B-A3B（寫碼專用，每 token 只啟用 3B，速度快；4-bit 約 45GB，ChatGPT 推薦）、gpt-oss-120b |
| 劇情、對白 | Claude | 本地模型寫草稿 |
| 視覺檢查 | Qwen3.8-27B | Claude |
| 第二意見（只限 256GB） | GLM-5.3-Flash（MIT；4-bit 約 204GB） | — |

本地模型的實際表現，要用自己的任務測試過才算數。到手後用同一批任務比較兩三個模型。

### 人設和概念圖（2D）
| 用途 | 模型 | 大小 | 授權 |
|---|---|---|---|
| 快速草圖、大量變體 | FLUX.2 klein 4B | 約 7.75GB | Apache 2.0（ChatGPT 引用） |
| | FLUX.2 klein 9B | 約 18.2GB | 要核實 |
| 高品質出圖 | Qwen-Image-2512 | 4-bit 約 26GB | Apache 2.0（ChatGPT 引用） |
| | FLUX.2-dev | bf16 約 64.4GB | 商用條件要核實 |
| 保持角色一致、修改圖片 | Qwen-Image-Edit | — | Apache 2.0（ChatGPT 引用） |
| 軟件 | Draw Things（免費，Mac 上最快）、ComfyUI（流程最靈活）、MFLUX（命令列，方便 agent 呼叫） | | |

建議流程：FLUX 快速出 16～32 個變體 → Qwen3.8 視覺評分 → 選最好的三個 → Qwen-Image 精修 → Qwen-Image-Edit 整理成三視圖（正面、側面、背面）→ 交給 3D。也可以訓練角色 LoRA 保持一致。

### 3D
| 用途 | 建議 | 備註 |
|---|---|---|
| 主角、重要角色 | Rodin（寫實人物最強）、Tripo H3.1 | 雲端 |
| 一般道具 | Meshy（有 REST API、自動綁骨）、Tripo（拓撲適合遊戲） | 雲端 |
| 大量雜物、原型 | Hunyuan3D 2.1、TRELLIS.2、TripoSG | 官方版本針對 CUDA，建議雲端 GPU；Mac 上有社群移植（image-to-3dlab、trellis2mlx、Hunyuan3D-MLX），較慢 |
| 修整 | Blender + Blender MCP | 減面、UV、材質、綁骨、LOD、碰撞 |
| PBR 貼圖 | Seamless Texture AI 一類、Unity AI 材質生成 | |
| 3D 世界生成 | HY-World 2.x | 官方建議多 GPU（例子用 8 張 H20），只用雲端 |

- AI 3D 輸出不等於可以直接用的遊戲資產。AI 做約七成粗工，Blender 修整仍然重要。
- **例外：預渲染 sprite 路線（Sword of the Guardian 的做法）。** 模型只用來渲染 2D 圖像，拓撲、減面、LOD、遊戲內效能大部分不再重要，修整工作大減。

### 預渲染 sprite 流程（2.5D 路線，2026-10-10 新增；2026-10-11 起只作後備選項，目前傾向即時 3D 角色）
```
AI 人設（三視圖）
  ↓
AI 3D 模型（Meshy / Tripo / Rodin，或本地生成）
  ↓
Blender：綁骨（Meshy 自動綁骨或 Blender 插件）→ 套用動作（動作庫或 AI 動畫）
  ↓
Blender 腳本批量渲染：固定鏡頭角度、光源、描邊或卡通著色，每個動作輸出 sprite 序列
  ↓
（可選）AI 修圖統一風格；或刻意降解像度做像素風
  ↓
打包成 sprite sheet → 遊戲引擎
```
- 優點：AI 可以全自動跑（Blender 有 Python API 和 MCP）；同一套模型可以重新渲染不同角度、解像度或風格；角色一致性由 3D 模型保證。
- 要注意：渲染風格（光源、描邊、色調）要寫入美術聖經，所有角色共用同一套渲染設定。
- 場景：3D 背景可以用 AI 3D 加 Blender 組合；Sword of the Guardian 當年評測認為場景較弱，這次可以重點用 AI 加強。
- Hunyuan3D 記憶體：官方 CUDA 版約形狀 10GB、貼材質 21GB（ChatGPT 引用）；Mac 移植版估計形狀約 24GB、貼材質約 48GB（3D Mate）。

### 動畫、影片
- 角色綁骨：Meshy 自動綁骨；動作用 AI 動畫工具或動作庫。主角的動作最易露出「AI 感」，值得花錢。
- 影片和過場：Wan2.2、HunyuanVideo 1.5（8.3B）等，建議雲端 GPU。

### 音樂、音效、配音
| 用途 | 建議 | 授權重點 |
|---|---|---|
| 音樂（商用最安全） | ElevenLabs Music | 訓練資料有授權，各方案都可商用 |
| 音樂（本地免費） | ACE-Step 1.5 | MIT；有 Apple Silicon 支援 |
| 音效 | Stable Audio 3 | 社群授權，收入 100 萬美元以下可商用 |
| 配音 | ElevenLabs 等雲端服務 | 確認方案包括商用；聲音複製要有同意 |
| 避免 | Suno | 正面對唱片公司訴訟 |

### 關卡、UI、測試
- 關卡：引擎的程序化生成加 AI 寫規則，再經 MCP 擺放。AI 最弱的一環，好不好玩要親自試。
- UI：Godot AI 或 Unity MCP 直接建立；也可以從 Figma 轉入。
- AI 試玩測試：自動建置 → 腳本或 AI 玩家跑上百次 → 收集數據（完成率、死亡次數、卡關率、時間）→ 本地模型找異常 → Claude 做設計審查。
- 「AI 美術總監」流程：生成 → 視覺模型評分（剪影、解剖、風格一致、可讀性）→ 只保留前幾名。否則 24 小時生成的結果會是一大堆沒人看過的圖。

## 三、記憶體管理原則
- 不要開機就把所有模型載入並常駐。
- 按工作時段載入：寫碼時段載入寫碼模型；美術時段載入圖像模型；做完就卸載。
- 大型生成器同一時間只開一個，由程式排隊。
- 256GB 的好處是不需要這麼積極地卸載；128GB 也做得到，只是要排隊。

## 四、3D 角色、綁骨和動畫工具（2026-10-11 補充）
| 工具 | 用途 | 綁骨 | 備註 |
|---|---|---|---|
| **Tripo** | 角色、道具、基礎模型 | 有自動綁骨（約 60 秒、20 credits；人形骨架） | Smart Low Poly 可大幅減面；匯出 FBX、GLB、OBJ、USDZ；Pro 約每月 US$19.90（3,000 credits，含商用授權），免費版每月 300 credits。有評測成功套用 Mixamo 動作到 Unity |
| **Meshy** | 道具、一般資產 | Meshy 官方說有自動綁骨；有一篇比較文章說沒有，**要自己測試** | 有 API、Blender 和 Unreal 插件；約每月 US$20 |
| **Rodin** | 高精度、寫實人物 | 未見提及 | 約每月 US$99；模型面數高，即時遊戲需要減面 |
| **Mixamo** | 人形自動綁骨 + 動作庫 | 有 | 免費（Adobe），適合走、跑、待機等基本動作 |
| **AccuRIG**（Reallusion） | 自動綁骨 | 有 | 免費 |
| **Cascadeur** | AI 輔助關鍵影格動畫，物理修正 | — | **適合格鬥招式**：出招前搖、命中影格、收招都要精確控制 |
| 影片動作捕捉（如 Rokoko Vision、Move.ai） | 用手機拍自己做動作，轉成動畫 | — | 適合大量一般動作 |

**對動作遊戲的重點：** 自動綁骨和動作庫可以處理走、跑、受擊等基本動作；但連技招式的手感來自影格數據（前搖、命中、硬直、取消時機），這是你當年的強項。招式動畫建議用 Cascadeur 或人手調整，不要完全依賴自動生成。

**建議：** 先用 Tripo 免費額度和 Meshy 試用，用同一張角色設計圖比較兩者的模型和綁骨品質，再決定訂閱哪一個，不需要全部訂閱。

## 五、音樂和音效方向（2026-10-11 補充）
**音樂（重製版必須重做，舊音樂不可用於續作）：**
| 做法 | 適合 |
|---|---|
| ElevenLabs Music：訓練資料有授權，各方案可商用；Pro 約每月 US$11 | 重製版的主力，商用風險最低 |
| ACE-Step 1.5（本地，MIT 授權） | 大量試作、氛圍音樂 |
| 人手作曲（外判） | 主題曲、頭目戰等最關鍵的幾首；香港項目更需要有辨識度的音樂身份 |
- 注意：純 AI 生成的音樂不受版權保護；Steam 要披露。

**音效：**
- 打擊感是 Sword of the Guardian 少數獲稱讚的地方，音效是打擊感的一半。
- 做法：先用音效素材庫作基礎（例如每年免費發放的大型遊戲音效合集），再用 AI 音效（ElevenLabs、Stable Audio 3）補充特定聲音；打擊聲要分層（衝擊、肉聲、武器聲）。
- 中介軟件：FMOD（獨立開發者在收入門檻以下可免費使用）可以做隨機變化、分層和即時混音，配合 Unity 使用。

**配音：** 重製版可以不配音或只做少量喊聲；香港項目的廣東話配音品質要另外測試。
