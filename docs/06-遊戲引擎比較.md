# 06 遊戲引擎比較（待決事項 #1）

> 這是最重要的待決事項之一，因為它直接決定 Mac Studio 要 128GB 還是 256GB。
> 2026-10-10 更新：加入「過往經驗」和「2.5D 預渲染路線」的考慮。
> **2026-10-11：已決定以 Unity 6 為主力引擎**（本人有 Unity 經驗，曾自行移植 Switch）。以下比較保留作參考。

## 一、過往經驗
- Sword of the Guardian 用 Unity 開發，Switch 版由本人自行移植。
- 有經驗的引擎可以省下大量重新學習的時間，而 Unity 6 對 AI agent 的支援也不錯。

## 二、比較
| | Unity 6 | Unreal 5.8 | Godot 4 |
|---|---|---|---|
| 官方 AI | Unity AI：編輯器內建助手，可以寫 C#、按圖片建場景、生成臨時資產；Generators 可做 sprite、貼圖、材質、音效、動畫、地形。每月 US$10 有 1,000 credits，Pro 方案已包括 | 原生 MCP 插件，可以讓 Claude 等模型操作 Blueprint、資產、關卡、材質、模型；Neural Network Engine（Beta） | 沒有官方 AI |
| 接外部模型 | AI Gateway（不耗 Unity credits）、官方 MCP 伺服器；ChatGPT 指有 Claude Code / Codex 官方插件（未獨立核實） | MCP 插件 | 社群插件 Godot AI：150 多種操作，一鍵連接 22 種 MCP 客戶端 |
| 對 AI agent 的友善程度 | 高：以 C# 程式碼為主 | 中：Blueprint 是視覺化腳本，AI 較難處理；C++ 編譯慢 | 最高：所有檔案都是純文字 |
| 2D / 2.5D（sprite + 3D 背景） | 成熟，2D 和 3D 可以混合 | 可以，但不是強項，殺雞用牛刀 | 2D 強項，也支援 3D 背景 |
| 主機發行（例如 Nintendo） | 官方支援，需要主機開發者資格 | 官方支援，需要主機開發者資格 | 要經第三方移植服務 |
| 在 Mac 上 | 穩定 | 支援一向不如 Windows；ChatGPT 引用 Epic 官方文件，指 Mac 不支援 Lumen 硬件光追和 MegaLights（未獨立核實） | 輕量、穩定 |
| 美術上限 | 高，足夠做 A 級風格化 3D | 最高，擅長寫實；有 MetaHuman | 中，適合 2D 和中小型 3D |
| 單人快速開發 | 最好 | 較慢 | 好 |
| 收費 | 個人版有收入門檻 | 收入超過門檻後分成 | 完全免費（MIT） |
| 記憶體和儲存需求 | 中 | 高（引擎和專案體積大） | 低 |

## 三、兩個 AI 的看法（在得知過往作品之前）
- **Claude：** 3D 首選 Unity 6（對 AI 友善、在 Mac 上穩定、資源多、你有 C# 經驗）；2D 或小型 3D 選 Godot；只有追求寫實畫面才選 Unreal，而且最好另備 Windows NVIDIA 機做最終畫質和效能測試。
- **ChatGPT：** 「想 AI 儘量代替開發團隊」→ Unity 更方便；「要做最好看的遊戲」→ Unreal。它當時偏向以 Unreal 作主力。

## 四、加入過往經驗後的看法（2026-10-10）
- 如果第一個項目延續 Sword of the Guardian 的 2.5D 路線（預渲染 sprite + 3D 背景），**Unreal 的主要優勢（寫實即時畫面）用不上**，Unity 或 Godot 更合適。
- 如果要再上 Nintendo 主機，Unity 和 Unreal 有官方支援，Godot 要經第三方移植。
- 如果當年用的是 Unity，Unity 6 會是最自然的選擇；如果是其他引擎，要比較「沿用經驗」和「轉用 AI 支援較好的引擎」兩者的成本。

## 五、怎樣決定
問自己：
1. 第一個項目是全新遊戲、續作還是重製？
2. 畫面是 2.5D 預渲染、風格化 3D，還是寫實 3D？
3. 要不要再上主機？
4. 當年的引擎經驗還有多少價值？

| 答案 | 引擎 | 對 Mac 配置的影響 |
|---|---|---|
| 2.5D 預渲染 / 風格化 + 重視 AI 自動化 + 可能上主機 | Unity 6 | 128GB 足夠 |
| 2D 或小型 3D，只上 PC | Godot | 128GB 綽綽有餘 |
| 寫實 3D + 接受將來加 Windows 機 | Unreal | 偏向 256GB |

建議：決定前，用同一個小任務（例如「一個角色在場景裡走動和攻擊」）在候選引擎各試一次 AI 流程，比較 AI 實際能完成多少。
